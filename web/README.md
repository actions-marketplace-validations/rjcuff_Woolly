# web

The usewoolly.com website and docs, built with React Router and Fumadocs and deployed on Vercel.

```sh
npm install
npm run dev     # http://localhost:5173
```

Docs pages come from `../docs/*.mdx` and must be listed in `../docs/meta.json`. Run `npm run types:check` and `npm run test:e2e` before a pull request.
