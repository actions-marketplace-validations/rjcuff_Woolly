## Install Woolly

<Tabs items={['Mac app', 'Windows app', 'macOS and Linux', 'Homebrew', 'PowerShell', 'Go', 'From source']}>
  <Tab value="Mac app">
    [Download Woolly for Mac](https://github.com/rjcuff/woolly/releases/latest/download/Woolly-mac.dmg), open it and drag Woolly to Applications. It works on Apple Silicon and Intel Macs, runs Woolly in the background and lives in your menu bar.

    To also get the `woolly` command in your terminal, run the macOS and Linux install.
  </Tab>
  <Tab value="Windows app">
    [Download Woolly for Windows](https://github.com/rjcuff/woolly/releases/latest/download/Woolly-windows.exe) and run it. It installs for your account without needing admin rights, runs Woolly in the background and lives in the system tray. Windows 10 or later.

    The installer isn't signed yet, so Windows SmartScreen may warn you the first time. Choose More info, then Run anyway.

    To also get the `woolly` command in your terminal, run the PowerShell install.
  </Tab>
  <Tab value="macOS and Linux">
    ```sh
    curl -fsSL https://usewoolly.com/install.sh | sh
    ```
  </Tab>
  <Tab value="Homebrew">
    ```sh
    brew install rjcuff/tap/woolly
    ```
  </Tab>
  <Tab value="PowerShell">
    On Windows, in PowerShell:

    ```powershell
    irm https://usewoolly.com/install.ps1 | iex
    ```
  </Tab>
  <Tab value="Go">
    ```sh
    go install github.com/rjcuff/woolly/cmd/woolly@latest
    ```
  </Tab>
  <Tab value="From source">
    ```sh
    git clone https://github.com/rjcuff/woolly
    cd woolly && make install
    ```
  </Tab>
</Tabs>

Check that it worked:

```sh
woolly version
```

## Check your agent files

```sh
cd your-repo
woolly check
```

Woolly reads CLAUDE.md, AGENTS.md, Cursor rules, Copilot instructions and your agents' memory, and flags every line that names a function, file or script the code no longer has, with the commit that changed it. It needs no setup and no model.

```txt
Checked 56 lines in AGENTS.md and .github/copilot-instructions.md against 20b0427.
  .github/copilot-instructions.md:30  Also update: `src/shared/api.ts`, `src/shared/providers/providers.json`
    src/shared/providers/providers.json was moved to apps/vscode/src/shared/providers/providers.json in 791d23899 (2026-05-25)
1 line names code that's gone. Your agents still read it as true.
```

`woolly check --fix` rewrites renamed names and moved paths for you. See [Check your agent files](/docs/memory-files).

## Check after every commit

```sh
woolly init --hooks
```

This starts project memory in `.woolly/`, brings in what your agent files already say, and checks again after every commit. Commit `.woolly/`, and every teammate's agents read and update the same notes. See [Project memory](/docs/project-memory).

## Connect your agents

```sh
woolly connect
```

This adds Woolly to Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Codex, Gemini CLI, LM Studio and opencode, whichever you have. Each session starts with the project's current facts and the lines that went stale, so the agent knows not to follow them. See [Connect your apps](/docs/connect).

To check pull requests too, add the [GitHub Action](/docs/pull-requests).

## Keep it running

```sh
woolly service install
```

Woolly now runs in the background and starts when you log in, like Ollama. The review page, the API and the [proxy](/docs/proxy) are always ready. Stop it with `woolly service uninstall`.

## Personal memory

Woolly also keeps a few facts about you, on your computer, out of every repo.

```sh
woolly remember "I prefer tabs over spaces" --key code.indent
woolly recall "tabs or spaces"
```

The `--key` names the fact, so a newer one replaces it. With [Ollama](/docs/ollama) running, Woolly also searches by meaning.
